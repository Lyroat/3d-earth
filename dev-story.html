3D Earth 开发流程

一个非程序员用 Cursor AI 从零搭建交互式 3D 地球科普网页

产品搭建阶段

1

🎯明确目标

确定做什么和给谁看。这个项目的目标是：做一个面向中小学生的 3D 地球科普网页，能直观展示板块构造、火山分布、地球内部结构等地学知识。

科普教育 中小学生 3D 可视化
2

🌐搭建主体

先让核心的东西出现——用 Three.js 创建一个可交互的 3D 地球模型。贴上 8K 高清地球贴图，加上凹凸地形，能拖拽旋转、滚轮缩放。这一步结束后，屏幕上有一个能转的地球了。

Three.js 8K 贴图 凹凸地形

功 能 循 环
3

🔧开发功能

逐个开发功能模块。每次聚焦一个功能，做完再做下一个。不贪多，做一个成一个。

  • 板块构造：三种边界类型 + 14 个主要板块导航 + 拆分动画
  • 火山分布：1416 座火山标记、搜索、分类筛选
  • 地球内部：剖面切割、7 层可视化、层级聚焦
  • 地球磁场：磁感线分布（开发中）
  • 日地月系统：自转公转（计划中）
4

🔍寻找数据与素材

每个功能都需要真实的科学数据。去专业网站和开源社区找可用的数据集、贴图、模型。

  • 地球贴图：Solar System Scope（NASA 级 8K 日照贴图）
  • 板块数据：GitHub fraxen/tectonicplates（PB2002 数据集，GeoJSON 格式）
  • 火山数据：史密森尼学会 Global Volcanism Program（1416 座火山）
  • 磁场数据：GitHub wb-bgs/m_IGRF、AnkitBarik/planetMagFields
NASA GitHub 开源 GVP 史密森尼
5

🐛调试与迭代

开发过程中最耗时间的部分。反复测试、发现问题、修改、再测试。对于非程序员来说，这个阶段也是学习技术术语的过程——得知道"CSS 是什么""Shader 是什么"才能和 AI 准确沟通需求。

  • Shader 剖面切割方案迭代了 6 个版本才成功
  • 云层效果尝试了 4 种方案后果断砍掉（理性止损）
  • 火山中英文翻译修正了 238 个错误
  • 学会了"CSS = 样式""JS = 逻辑""Shader = 着色器"等关键概念
反复迭代 学习术语 理性止损
6

📝增加注释

在代码关键位置加上人类可读的注释，标注"这段代码控制什么""修改哪个数值会影响什么效果"。这样后续想手动微调某个参数时（比如地球转速、颜色深浅），不用每次都问 AI，自己就能动手。

降低维护门槛 人工可调

7

🚀部署上线

把网页部署到线上，让别人也能打开看。用 Vercel 一键部署，关联 GitHub 仓库，每次提交代码自动更新。

Vercel 自动部署
8

📦结构重构与文件瘦身

项目跑通之后回头整理"房间"。把 1700 行的单文件拆分为独立的 HTML + CSS + JS，按功能模块归入不同文件夹，清理不需要的大文件（60+ MB 的贴图）。

  • v2.0 重构：单文件 → 模块化文件结构
  • 按功能分文件夹：earth/、plates/、volcanoes/、interior/、magnetic/
  • 清理 git 中的大文件，创建 .gitignore
v2.0 重构 模块化
9

🎛交互逻辑优化

调整用户操作的逻辑和层级关系。哪些按钮该放在一起、面板怎么组织、操作流程是否顺畅。

  • 底部弹出菜单 → 左侧面板（信息层级更清晰）
  • 板块导航加滚动条，避免列表过长
  • 面板宽度自适应文字内容
  • 统一各面板的视觉风格
UI/UX 信息层级
10

✨内容丰容

在功能框架之上补充内容深度。增加科普知识卡片、优化配色和视觉质感，让产品从"能用"变成"好用且好看"。

  • 知识卡片：板块边界图文说明、各地层详细信息、火山类型介绍
  • 外核动态熔流动画（模拟热对流物理现象）
  • 内部着色：连续径向渐变替代分层色块，过渡更自然
  • 术语修正：确保科学名词准确（"汇聚型""离散型""过渡带"）
知识卡片 视觉精修 科学准确
建议

📁及早瘦身，控制文件体积

大贴图和过长的单文件会导致 AI 读取超量，需及时拆分模块、排除大文件

✂️敢于砍掉不合适的功能

云层效果试了 4 版都不理想，且与核心主题关联不大，果断砍掉不影响使用

🔬科学数据不能盲信 AI

1416 个火山名称中有 238 个翻译错误，科学术语也需人工核实

🐙善用 GitHub 开源资源

很多数据和模型是现成的，可以直接获取使用。本项目用到的开源项目：fraxen/tectonicplates（全球板块边界 GeoJSON）、wb-bgs/m_IGRF（国际地磁参考场模型）、AnkitBarik/planetMagFields（行星磁场可视化）

🧊了解一下 Three.js

Three.js 是一个 JavaScript 3D 渲染库，能在浏览器中创建 3D 场景。本项目用它实现了地球模型渲染、板块边界绘制、火山标记、内部剖面切割等所有 3D 效果。它还可以做 3D 产品展示、数据可视化、游戏、建筑漫游、虚拟展厅等

在线体验：earth-volcano-3d.vercel.app

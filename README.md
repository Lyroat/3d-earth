# 3D Earth 2.0 — 地球与太阳系交互观测台

一个基于 Three.js 的三维科普网页应用，包含地球探索、真实比例太阳系观测，以及日地月系统教学观测，可在支持 WebGL 的浏览器中运行。

**当前版本：2.0（`v2.0.0`） · 更新日期：2026-11-24**

## 2.0 更新亮点

- **太阳系观测台**：新增太阳、八大行星、月球与示意小行星带；原尺寸下，天体大小与天体间距离使用同一比例。
- **星历与时间控制**：使用 Astronomy Engine 计算位置及自转姿态；支持实时、加速、暂停和 UTC 日期跳转。
- **原位观察放大**：原尺寸 / 10× / 25× 档位，太阳与行星在原位置同步放大，不移动轨道或生成移位副本。10× / 25× 是可视化档位，**不是实际半径倍数，也不保持天体大小比**。
- **日地月同页切换**：从首页进入“太阳系观测”，再切换“日地月系统观测”；分别保留镜头、演示时间、速度和显示开关。日地月仍为教学示意比例，不是当前星历。
- **统一界面**：地球专题与太阳系采用同一套观测台视觉；日地月左栏使用星球小图标，辅助显示统一为无 emoji 的开关列表。
- **分至点独立控制**：两个分点、两个至点可分别显示或隐藏，导航跳转不会重开已隐藏的点；修正至点标记与导航位置不一致的问题。

保留原有地球板块、火山、地震、内部结构及地磁场等功能。本次发布聚焦网页功能，不包含本地尚未发布的 iOS 打包工程。

## 功能介绍

### 🪐 太阳系观测
- 原尺寸下，`1 场景单位 = 1 AU`，尺寸和距离同尺；支持太阳、八大行星及月球
- 基于 Astronomy Engine 2.1.19 的解析星历与 IAU 姿态模型，展示公转、自转和转轴方向
- 天体导航、太阳系全景、内太阳系、俯视及近距离跟随观察
- 原位观察放大、金星云层 / 地表切换、土星环贴图
- 天体名称、公转轨迹、自转轴、小行星带及其定位点可单独开关
- 1,600 个固定种子的示意小行星，使用程序岩石材质；不是实际小行星目录，定位点大小不表示岩块大小
- 实时至 30 天/秒的时间流速、暂停、回到此刻和 1900—2100 年 UTC 时间跳转
- 默认真实比例，观察放大与日地月教学比例均明确区分；精度与显示限制见 [太阳系说明](Solar_System/system/README.md)

### 🌍 地球本体
- 8K 超高清地球表面贴图，支持凹凸地形开关
- 自动旋转，支持鼠标拖拽、滚轮缩放、双击放大
- 经纬网格叠加显示

### 🔶 板块构造
- 基于 PB2002 科学数据集，绘制全球板块边界（汇聚边界、离散边界、转换断层）
- 不同类型边界以不同颜色区分，鼠标悬停显示边界类型
- 点击边界类型弹出知识卡片，展示对应图文说明
- 14 个主要板块导航按钮，点击可旋转至对应板块位置并高亮
- 板块拆分功能：点击后 14 个主要板块向外展开，直观展示板块形状与轮廓
- 小板块自动归并至所属主要板块（如巽他板块归入欧亚板块、索马里板块归入非洲板块、澳大利亚板块归入印度洋板块）

### 🌋 火山数据
- 展示全球 1416 座火山，按活跃度分为活火山、休眠火山、死火山三类
- 不同类型以不同颜色标记，带闪烁动画效果
- 鼠标悬停显示火山详细信息：中英文名称、类型、活跃度、地理位置、上次喷发时间
- 火山位置重叠时自动弹出聚合列表，点击可选择具体火山
- 按类型筛选、搜索火山（支持中英文）
- 点击火山自动推进放大，按 Esc 返回

### 📍 地震分布
- 基于 **USGS Earthquake Catalog API** 实时获取全球地震数据
- 实心光球标记地震位置，边缘清晰，颜色和大小随震级变化（绿→黄→橙→红→深红）
- 五级震级划分筛选：微震（<3）、有感地震（3-4.5）、中强地震（4.5-6）、强震（6-7）、大地震（7+）
- 按震级自动调整默认时间跨度：微震近3个月、有感近1年、中强近5年、强震近20年、大地震全历史
- 支持自定义年份范围查询：输入起止年份，按指定时段加载任意震级地震
- 鼠标悬停显示详细信息：地点、时间、震级、深度
- 与板块边界联动展示，直观呈现地震与板块构造的空间关系
- 数据缓存机制，避免重复请求

### 🧲 地磁场
- 基于 **IGRF-14**（国际地磁参考场，2025.0 纪元）高斯系数，球谐展开至 l=6 阶
- RK4 数值积分追踪磁感线，从多个纬度带均匀播种
- 磁感线颜色按纬度渐变：地磁北极区域蓝色，地磁南极区域红橙色，中间平滑过渡
- 磁感线延伸至地球内部，连接中心条形磁铁
- 开启磁场模式时地球半透明，可见内部条形磁铁（N 极朝南、S 极朝北）
- 标注地磁北极和地磁南极位置

### 🌐 地球内部结构
- 交互式剖面视图，展示地球分层结构
- 七层可视化：地壳、岩石圈地幔、软流圈、过渡带、下地幔、外核、内核
- 支持按层级聚焦：地幔/地核整体，上地幔/下地幔子层，以及岩石圈视图
- 悬停显示各层详细信息：深度、温度、成分、物态
- 自定义 Shader 渲染截面纹理，模拟真实地质质感

### ☀️ 日地月系统观测
- 太阳、地球、月球三体教学可视化（目前尺寸与距离为便于观察而调整，并非统一真实比例）
- 地球公转与月球公转联动，支持速度滑块调节
- 地球自转轴倾斜 23.4°，示意昼夜与季节变化；地球中心公转视角不随公转旋转地轴方向，保留手动旋转与缩放
- 真实阳光照明：太阳光照射地球和月球产生明暗变化
- 两种观察模式：公转模式（俯瞰轨道系统）、自转模式（聚焦地球昼夜）
- 四个分至点标记（春分/夏至/秋分/冬至），可分别开关；分至点导航可跳转并打开科普卡片
- 赤道、南北回归线及南北极圈随“标注与纬线”统一开关；阳光光束和直射点另有独立开关，保留地球薄蓝色轮廓辉光
- 公转/自转知识卡片互斥显示，分至点按钮互斥切换

### 🎛 交互与 UI
- 统一观测台风格：深蓝黑底色、低饱和金色强调、左侧功能、右侧知识卡片、底部场景控制
- 地球首页只提供“太阳系观测”入口；进入观测台后，顶部可切换“太阳系观测 / 日地月系统观测”
- 地球模式左侧面板分为「内容显示」（地形/板块/火山/地震快速开关）和「地球探索」（板块/火山/地震/内部结构/磁场手风琴面板）
- 日地月系统观测左栏复用太阳系的星球小图标导航和“辅助显示”开关样式，无 emoji；含观察中心、分至点导航、标注 / 纬线、轨道、阳光直射和四个分至点的独立开关；底部为独立的教学速度与暂停
- 切换保留各自镜头、速度、时间和开关，不混用真实太阳系比例与教学示意比例；仅更新当前场景
- 知识卡片系统：点击功能按钮弹出对应科普信息
- 暂停/继续、复位按钮
- 拆分板块时切换功能自动合并复位
- 键盘快捷键：Esc 返回/关闭面板

## 技术栈

- **Three.js 0.164** — 3D 渲染（WebGL）
- **Line2 / LineMaterial** — 高质量粗线条渲染（磁感线、板块边界、轨道线）
- **自定义 ShaderMaterial** — 地球表面均匀光照、凹凸贴图、地球内部截面纹理
- **MeshPhongMaterial** — 日-地-月系统真实光照响应
- **IGRF-14 球谐模型** — 地磁场物理计算
- **Vite / ES Modules** — 多页面开发、按需加载教学模块与本地资源构建
- **Astronomy Engine 2.1.19** — 太阳系星历与 IAU 姿态模型（不用于示意教学时钟）

## 运行

推荐使用 Node.js 22 LTS 或更新的 LTS 版本。

```sh
npm ci
npm run dev -- --host 127.0.0.1
# 地球：http://127.0.0.1:5173/
# 太阳系：http://127.0.0.1:5173/Solar_System/system/
# 日地月：http://127.0.0.1:5173/Solar_System/system/#sem
npm run test:solar
npm run build
```

部署构建后的 `dist/`；不要通过 `file://` 直接打开模块页面。

`npm run test:solar` 目前包含 35 项自动测试，覆盖真实比例、观察放大、星历参考值、模式切换、独立时钟、地轴、分至点开关、辅助显示事件与界面结构。`npm run build` 构建地球、管理页和太阳系三个入口。

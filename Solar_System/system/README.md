# Solar System Observatory 2.0 · 真实比例太阳系

版本：**2.0（`v2.0.0`）** · 更新日期：2026-11-24。属于 3D Earth 2.0 网页发布，复用原有地球素材和地球专题，不包含本地 iOS 打包工程。

统一观测台页面，顶部可切换“太阳系观测 / 日地月系统观测”；根首页只提供“太阳系观测”入口，不再单列日地月入口。两种模式的比例、时钟和状态独立，地球专题留在根页面并使用同一套视觉样式。

## 本地运行

```sh
npm install
npm run dev -- --host 127.0.0.1
# http://127.0.0.1:5173/Solar_System/system/

npm run test:solar
npm run build
```

Vite 多页面构建会生成 `dist/Solar_System/system/index.html`。所有贴图通过 `new URL(..., import.meta.url)` 构建，不依赖 CDN 或远程图片；原有 `base: './'` 和 iOS 配置保留。

## 操作

- 默认“太阳系观测”。进入观测台后，顶部切换“日地月系统观测”无需离开页面；`http://127.0.0.1:5173/Solar_System/system/#sem` 深链接保持可用。
- 默认真实尺寸（×1）、设备当前时刻、实时速度。
- 点击左侧天体或其定位标签，进入近距离公转跟随；镜头不跟随天体自转，拖拽 / 缩放不会暂停时间。
- 近距离观察设有放大上限：按所观察天体的显示半径（含土星环）、当前档位及横竖屏视角计算最小距离，天体最大角半径为短边半视角的 85%，留出画面边距，避免无限放大或贴近表面。滚轮、中键拖动、触控缩放及 ＋ 按钮共用限制；平移不能绕过天体周围的距离保护，达到上限仍可旋转或拉远。太阳系全景 / 内太阳系 / 俯视以太阳为观察中心，聚焦后以对应天体为中心；日地月仍使用自己的距离限制。
- 原尺寸 / 10× / 25×：原尺寸保持真实比例；**10× / 25× 现在是可视化观察档位，不是真实半径的倍数**。直接缩放原有的太阳、行星本体和土星环，不生成额外球体、移位预览或引线。中心位置、轨道、自转与公转不变。
- 观察模式下按相机距离设置最低可见尺寸，并保留少量大小差异。远景中地球直径为 14 / 35 CSS px，其他行星的参考直径为 `1.4 × 档位 × (参考半径 / 地球半径)^0.2`；土星参考半径包含环。近景中显示半径不小于真实半径乘档位。不同天体间的显示大小比已压缩，不能当作实际大小比；页面显著标明“尺寸示意”。随拖拽、缩放、窗口大小和天体公转逐帧更新，但始终缩放同一个三维球体，不偏移中心。
- 太阳采用与行星相同的观察尺寸规则，远景中 10× / 25× 的最低直径约为 36 / 89 CSS px；近景同样保留真实半径乘档位的下限。月球仅按半径乘 10 / 25 缩放，不应用最低可见尺寸，避免在全景中盖住地球。观察模式行星补光由 0.025 增至 0.18，以看清夜面；太阳仍使用原贴图与自发光材质，太阳方向和昼夜分界不变。切回原尺寸即全部恢复真实尺寸和原补光。
- 全景、内太阳系、俯视下切换档位不移动相机或目标。太阳放大后可能遮挡内侧行星，真实位置接近的行星间也可能重叠，不为避让而移动天体；可切换内太阳系或拉近观察。
- 仅当聚焦太阳或其他天体的镜头过近、会穿入放大的天体或严重裁切时，才退到安全距离；10× / 25× 的安全取景仍保留递增的视觉大小。缩小倍率不自动拉近，可用“聚焦所选”重新取景。
- 全景、内太阳系、俯视、聚焦所选；名称、轨迹、自转轴、小行星带及其定位点均可开关。
- 统一时间加速（1× 至 30 天/秒）、暂停、回到此刻、UTC 日期跳转（1900—2100 年）。高速自转存在帧采样混叠，不能凭视觉转动方向判断物理模型。
- 金星可切换云层 / 地表。
- 页面不再显示底部视角说明（包括“跟随某天体”）、右上角比例徽标、模型说明按钮和右侧卡片中的观察模式长说明；聚焦跟随、时间控制和尺寸切换均保留。模型精度、比例限制及数据来源保留在本文件中，放大模式仍在操作区提示“尺寸非比例”。
- 大屏 UI 随窗口宽高自适应：文字、按钮、开关、两侧栏和时间条使用 `rem` 同步放大，普通屏幕与小屏保持原布局，最大为基础尺寸的 2 倍；侧栏和知识卡片保留滚动，不挤占底部时间条。浏览器默认字体及缩放仍生效；只调整界面，三维比例、镜头和鼠标投影坐标不变。天体标签的避让间距与标尺目标长度同步适配。

### 日地月系统观测

- 完整迁入原有教学场景：自转 / 公转、太阳 / 地球中心、四个分至点及知识卡片、五条纬线与标注、阳光光束和直射点开关、地球薄蓝色辉光。
- 左栏太阳 / 地球中心使用与太阳系相同的彩色星球小图标、纵向导航行和选中状态，不使用 emoji；“辅助显示”复用相同标题、行距、字体和开关，窄屏也可滚动操作。
- “辅助显示”包含标注与纬线、轨道线、阳光直射，以及北分点、北至点、南分点、南至点四个独立开关。关闭某一点会同时隐藏其标记与文字，不影响其他点；“标注与纬线”统一隐藏纬线及分至点文字，不改变四个点自身的显示设置。导航跳转和模式切换不会重开已隐藏的点。
- 分至点位置采用与地球公转相同的 Three.js 坐标约定，修正原来两至点标记与导航位置相反的问题；中英文名称与场景标记保持一致。
- 保留教学尺寸：太阳半径 2、地球轨道半径 18、地球半径 0.35、月球轨道半径 1.2、月球半径 0.095。**不是真实比例或当前星历**，不套用太阳系的 AU、UTC 或观察放大规则。
- 演示速度 0—5×、独立暂停；暂停时拖动速度不自动继续。自转改用经过时间更新，60 / 144 Hz 显示器的速度一致，原 60-fps 观感不变。
- 地球中心公转时只平移镜头，不随公转旋转相机偏移；拖拽、缩放不暂停时间，不强制太阳位于屏幕右侧。
- 退出模式不重置状态，再次进入保留视角、速度、暂停、开关与知识卡片。非当前模式不更新、不渲染；切换不补算退出期间的时间。
- 教学模块按需导入，共享已载入的太阳、地球和月球贴图；一个渲染器与动画循环，两个隔离的 Scene，避免太阳系照明污染教学场景。

## 数据与坐标

1. **比例**：`1 scene unit = 1 AU = 149597870.7 km`。原尺寸下尺寸和距离同尺；观察档位的球体尺寸为示意，但中心间距离始终不变。采用赤道 / 极半径椭球，太阳名义半径 695700 km。土星主要可见环中心半径约 66900—140180 km；不模拟 E 环等微弱延伸。
2. **位置**：Astronomy Engine **2.1.19** `HelioVector`，太阳中心的几何位置，不加观测光行时；`Rotation_EQJ_ECL` 转到固定 J2000 黄道，再映射为 Three.js `(x, z, -y)`，保持右手系。月球同样使用星历而非画圆。
3. **自转**：`RotationAxis` 返回转轴及 IAU 参考经线旋转角。构造参考赤道节点与正交基，将球体北极沿真实轴向摆放，再应用参考经线相位。地球含库中的岁差 / 章动，月球含天平动；金星、天王星逆行。
4. **轨迹**：每颗行星在当前历元前后一个参考恒星周期内采样（256 段），月球为地心采样（128 段），使用折线而非强行闭合。跳转日期及每跨一年重新采样。轨迹只是辅助路径，不驱动位置计算。
5. **精度**：解析星历适合科普，不承诺 JPL DE 级精度。测试含 JPL Horizons DE441 的地球及海王星独立参考向量（JD 2461367.5 TDB / J2000 黄道 / AU-D），门限分别为 2000 / 500000 km，实测约 718 / 334709 km；单一历元的抽查不等于全时间、全天体精度保证。海王星参考自转采用该库 IAU 模型的约 15.97 小时，而非其他观测方法的 16.11 小时。
6. **显示精度**：聚焦天体作为浮动原点，双精度计算后再提交 GPU；对数深度及动态 near plane 支持从海王星轨道到月面尺度。不把坐标距离压缩为对数。

### 素材

- 太阳、月球、八大行星及土星环复用 `../textures/`。
- 地球复用 `../../earth/main/earth.jpg`；不恢复已废弃的新地表 / 悬空云层方案。
- 金星地表按需载入，默认显示云层；8192×500 土星环 PNG 按横向径向条带映射。
- 原图文件不改写；GPU 贴图副本长边限制为桌面 4096 / 窄屏 2048 px（同时受显卡上限约束），避免多张 8K 图的 mipmap 占用过多显存。
- **小行星没有假称 AI 生成的 PNG**：`asteroids.js` 程序生成变形岩块与三维颗粒 / 岩层着色材质，可直接使用且无图片接缝。当前没有可用的内置生图接口，若后续需要独立 AI 位图，需另外确认带 API Key 的生图方案。

### 小行星带与显示辅助

1600 个固定种子的示意样本（非观测目录），半长轴 2.1—3.3 AU，部分位置粗略避开柯克伍德空隙；每个样本沿开普勒椭圆运行，岩块半径 0.5—50 km。实体始终为真实尺度、不参加行星放大，默认定位点为固定屏幕尺寸的辅助标记（可单独关闭），不是密集实心环。

天体标签也不是天体大小，背景星点不是恒星星表。亮度为归一化展示，太阳光方向是真实几何方向；不模拟逆平方曝光、食、环影等。贴图云层和零经线未与当天影像校准，气态行星 / 太阳只用参考整体转速；未模拟金星云层超旋转。

当前覆盖太阳、八大行星、月球和示意主带；暂不包含其他卫星、矮行星、柯伊伯带。

## 文件

| 文件 | 职责 |
|---|---|
| `index.html` / `system.css` | 独立观测台界面与控制栏 |
| `system.js` | 渲染、真实尺度、贴图、交互、浮动原点和统一时钟 |
| `data.js` | km / 天等物理常量，半径、公转周期、参考参数 |
| `astronomy.js` | 星历、IAU 姿态和轨迹采样；不包含显示放大 |
| `appearance.js` | 真实尺寸还原、原位可见尺寸下限、逐帧缩放和防穿入取景 |
| `zoom-limits.js` | 随天体半径与窗口视角计算近距缩放上限，平移后的距离保护及控制器限幅 |
| `mode-controller.js` / `view-state.js` | 异步模式切换、防竞态、镜头状态保存与还原 |
| `asteroids.js` | 可复现示意群体、开普勒位置、程序岩石材质 |
| `../sem/model.js` / `sem.js` / `sem-ui.js` | 教学时钟与状态、纯场景 API、教学控制与知识卡片适配 |
| `../../ui/theme.css` / `earth-ui.css` | 两页共用视觉变量、导航、按钮及地球专题皮肤 |
| `../../ui/screen-space.js` | 将相对 UI 尺寸转换为标签避让和标尺所需的屏幕像素间距，不修改三维比例 |
| `system.test.js` | 比例、几何可见性、星历、双模式切换、教学时钟、地轴、标注和 DOM 完整性测试 |
